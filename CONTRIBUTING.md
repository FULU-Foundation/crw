# Contributing to Consumer Rights Wiki

Thanks for wanting to contribute.

By contributing, you confirm you're the original author of your submission, have the rights to submit it, and agree it can be licensed under this project's license.

## Reporting bugs

This tracker is only for the codebase and associated infrastructure. If you're using the wiki and something's not working, report it on the wiki's own [Bug reporting page](https://consumerrights.wiki/w/Consumer_Rights_Wiki_talk:Bugs) instead. For issues with, or contributions to, our browser extension, use [FULU-Foundation/CRW-Extension](https://github.com/FULU-Foundation/CRW-Extension) instead.

Open an issue: https://github.com/FULU-Foundation/crw/issues

Before reporting:
- Check for duplicates: look through existing issues before posting to avoid repeats

Include:
- System details: OS, browser, and platform (e.g. Windows, macOS, Linux, x86, ARM, Chrome, Edge, Safari, Firefox)
- Where it happened: consumerrights.wiki, staging, or self-hosted/local dev
- Inputs and outputs: what you did, what you expected to happen, and what actually happened
- Reproduction steps: clear, step-by-step instructions so we can replicate it
- Screenshots, console errors, or server logs, if relevant

**Security issues**: do not open a public issue. Email security@fulu.org instead.

## Suggesting features

Open an issue describing the problem it solves and your proposed solution.

## Contributing code

1. Set up your dev environment (see README.md)
2. Look for issues tagged `good first issue` or `help wanted`
3. Open a PR

Commit messages: keep them simple, to the point, and legible.

Want a staging account for testing? Our staging instance can be used as a development sandbox for contributors. Get in touch with Jake to have one set up.
